# 安全比值测试设计（实施前静态审查）

当前统一并列带可能制造超过绝对可行性容差的负人工或负松弛变量。修复方向是：所有阻挡共同限制安全步长，再在原并列集合中按既有规则选择主元。不得撤回有限值／负人工守卫，不调整一般容差，不依据p0033调阈值。

2026-11-13补充事实：主agent已用扩容proof_profile确认p0033在冻结099e545基线上有125条失败记录，其中124条为不可行、1条为iteration_limit；唯一数值故障为第4行人工变量=-0.0015374175338724767，phase1_pending=true，形成1个unresolved节点。九项非时间字段与screen base逐位一致。该事实确认守卫诚实截断，但尚不能仅由此区分并列带、小主元过滤或其他数值误差的直接成因。

## 现有机制及缺口

两个实现分别在milp/src/simplex.rs::ratio_test与milp/src/simplex_sparse.rs::ratio_test。基变量沿进入方向变化为x_i(t)=x_i-alpha_i*t，其中alpha_i=delta*a_i。旧逻辑允许选择t_min+band内的较大比值，实际界违反却是abs(alpha_i)*(t-t_i)。默认feas=1e-9，现有cap仍允许band=1e-6，alpha=1已可产生千倍于feas的越界；B^-1*A方向可以大于1，原始行归一化不能消除这个问题。

已确认的Phase-1反例为x>=0，先排x=1000+GAP，再排x=1000，GAP=2^-21。并列时第一行离基，第二人工变量变成-GAP。加上第二行0.5*y的两步变体，还可能用后续零步主元换出负人工并抹掉证据。当前guard正确拦截，不应回退。

小主元还有独立缺口：旧代码把abs(a_i)<pivot的阻挡行从候选中删除，仅在候选全部为空时返回FilteredBlock。它可能比另一个可用大主元更早阻挡。不能作为主元不等于可以穿越它的界。

## 推荐的最小两遍纪律

1. 第一遍扫描全部基行。先核验方向有限性，再判断运动方向是否存在有限活动界。alpha_i>0时d_i=x_i-lb_i；alpha_i<0时d_i=ub_i-x_i。所有有限活动界均进入安全上限T_i=(d_i+epsilon)/abs(alpha_i)，epsilon只用既有tol.feasibility。全局T=min(T_i)。小主元同样限制T，只是不具备离基资格。
2. 进入变量自身也是斜率1的虚拟阻挡。有限宽度w=ub-lb对应安全上限w+epsilon；实际Flip仍移动到精确对端界，步长为w，不能把松弛后的上限当成翻转距离。
3. 第二遍保留旧的有限名义步长、旧t_min及旧band，仅在原候选集合与t<=T的交集中选择。普通模式按最大abs(主元)，再最小基变量列号；Bland模式按最小列号；Flip使用进入列号。不要把Harris上限直接替换旧并列窗并扩宽候选集合。旧胜者仍通过安全检查时，其步长与破键结果保持。
4. 任意有限活动界先记为存在阻挡，再做算术及主元资格检查。存在阻挡却没有安全可用候选，返回FilteredBlock。只有方向全部有效，且行与进入变量均没有有限活动界时，才能返回NoBlock。
5. 修改基之前按do_pivot/do_flip的实际运算顺序复核所有拟更新基值、新进入变量值及离基贴界误差。失败保持旧基，沿既有数值失败／重构通道，不夹值继续，不收费未执行的工作步。普通浮点算出的cap不能独自充当严格安全证明。

既有容差内略越界的状态须扣除已经消耗的预算。例如d_i=-0.8*epsilon，只剩0.2*epsilon余量；必须用真实d_i+epsilon，不能用max(d_i,0)+epsilon。入口已经越界超过epsilon时，上述归纳前提不成立，应修复或数值失败，不能用max(负比值,0)掩盖。

## 保证范围与浮点实现

精确算术下，向下运动的行有x_i(t)-lb_i=d_i-alpha_i*t>=-epsilon，另一侧界因运动方向不会恶化；向上运动对称，进入变量由自身虚拟阻挡保护，其他非基变量不动。这同时保护全部变量的有限上下界，不应只给人工行特殊cap。

该结论依赖入口可行，以及alpha真实表示当前基方向。它保证当前基表示的界可行性，不替代原方程残差检查和因子化有效性检查。若要把可行性作为每步不变量，重构后的全部基值也需按相同前提核验；仅查人工负值不能保证普通基变量可行。Phase-2残基人工变量还须保持近零，不能把[0,+infinity)的列边界误当成原模型允许它吸收约束的授权。

cap算术与实际更新存在舍入差异。至少要在基修改前复核拟定值；Flip复核应使用实际new_value-old_value，而不擅自改成另一种乘加顺序。若实现有向舍入，不能假定仅对最终商next_down一次就包住减法、加法、除法的所有误差；也需保留精确零／零容差退化情况。不得为通过复核额外放宽epsilon。

## 非有限算术

合法ub=+infinity表示没有该侧阻挡；有限ub、lb之差溢成infinity表示计算失败，两者必须区分。d_i、d_i+epsilon、名义比值、安全比值及实际更新量均应检查，不能把Inf/NaN塞进候选或用max(0)吞掉NaN。

现有实现并非将有限差值溢出直接当成NoBlock，而会把Inf候选保留并可能输出Flip{t:Inf}/Leave{t:Inf}。公开LP为x∈[-1e308,1e308]、min(-x)、无约束：真最优取值+1e308、目标-1e308。2026-11-13以当前主树c88c47e公开API实测：Dense/Revised与Min/Max的release四例均返回正确有限端点，debug四例均在do_flip的Inf-Inf断言处panic，被catch_unwind捕获。没有测得falseUnbounded，不能将其宣称为已确认falseUnbounded。

首版无法稳健计算有限阻挡时，可诚实返回FilteredBlock；不得静默删除阻挡、输出无限步长或给出Unbounded证明。不必在本轮扩展到一般大数算法或容差调整。

## 恢复和B&B语义

稠密ratio/步后失败直接转为IterationLimit；稀疏numerical_retry_or_fail至多重构一次，但步后重构的是已经换过的基，不会回滚错误离基选择。真实负人工可能仍然存在。安全检查应尽可能前移至旧基尚未改变时，并保留现有重构、期限、工作余额和guard顺序。

B&B将失败子树旧est记入unresolved_bound、设置粘滞limit_hit，再处理其他子树。即使栈最终为空，仍必须LimitReached，不能因为incumbent达到已知最优就冒称证明完成。p0033 profile已确认负人工，但一般诊断仍应区分numerical_error与单LP真正的迭代上限。

## 最小回归矩阵

- 冲突等式单步／两步变体、行序反转、Min/Max、冷solve／首次resolve：安全比值应证明Infeasible。人工注入坏状态的guard测试仍须保持拒绝。
- 相同等式及容差内差距：不误判，钉住容差边界。
- 原有安全并列：t_min=2，方向0.5与1，比值差5e-10，继续按较大主元选第二行。
- 放大反例：方向4与8，名义比值1与1+2^-30；旧选择使第一行越界约3.7e-9，应拒绝该大主元并选安全早阻挡。
- 对称上界阻挡和delta=-1，覆盖alpha负方向。
- 进入变量自身翻转先于离基候选；精确并列、Bland以基变量列号而非行号破键。
- 小主元早阻挡，分别配安全大主元、不安全大主元和无其他候选；不能直接穿越，也不能误报无界。
- NaN/Inf方向、有限差值／比值／宽度溢出、真正无界；严格区分FilteredBlock与NoBlock。
- 无人工Phase-2自然反例已由微型公开API harness核验：x,y>=0，max x+0.1*y；先x<=1000+2^-21，再x+0.5*y<=1000。Dense/Revised、Min负目标/Max正目标、release/debug共8个危险行序配置全部误Optimal，x=1000.0000004768372,y=0，原第二约束残差恰为2^-21=4.76837158203125e-7，目标为正负1000.0000004768372而真最优为正负1000。交换行序的8个对照均正确。因此一般primal步长安全是独立正确性修复，不仅用于减少guard后的LimitReached。

自然负人工回归中硬编码IterationLimit的预期需改为修复后的Infeasible；只有一步工作余额时仍须尊重预算优先级，不能全部重钉为不可行。换基、界翻转收费规则和期限优先级不变。

## 实施接口与范围

可保持Step枚举不变，抽出纯计算接口：(value, signed_direction, lower, upper, feasibility) -> {nominal_t, safe_cap, hit_upper, has_blocker}或明确数值失败。主元资格由raw abs(a)与pivot单独判断。稠密提供matrix[i][q]/rhs[i]，稀疏提供alpha[i]/x_b[i]；公式、有限性检查顺序、破键与回归数据对齐。

优先只改两套原始比值测试及必要的步前复核，不同时重设定价、反循环、容差或B&B。若新增普通基变量步后守卫，要明确其保证与Phase-1/2前提，不以改终检阈值代替修复。

正常成本应为额外O(m)安全上限和拟更新扫描，复用暂存空间，无稠密矩阵复制。可能减少失败子树、恢复证明能力，也可能因排除危险大主元而改变退化路径或增加迭代，需独立门禁检验，不能由p0033单例推断性能。
