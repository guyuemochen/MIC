# 原始单纯形安全比值验证

本轮修复两套原始单纯形共享的界可行性缺陷：旧并列窗只能限制步长差，不能限制乘上方向后的变量越界；低于主元阈值的阻挡也不能被其他候选穿过。基线为 `22fbcf8`，生产改动仅在 `simplex.rs` 与 `simplex_sparse.rs`；未改默认特性、一般容差、定价、分支定界、预处理或启发式。

## 最终行为

全部有限活动界（含小主元和入基变量自身）共同形成安全步长上限，使用真实距离加既有绝对可行性容差。已有轻微越界会扣除剩余额度。候选仍取原名义步长和原并列窗，仅排除不安全项；安全旧胜者保留步长与破键。按实际换基或翻转的浮点顺序复核全部基本值、入基值及离基贴界误差；失败尝试原窗内次选，全部失败沿既有数值失败或重构路径退出，未执行步骤不收费。有限距离或比值溢出不能输出无限步长，只有真实无活动界才允许无界结论。

阶段入口、步后和重构后的基本值检查补齐全部上下界。人工变量第一阶段仍为 `[0,+∞)`，第二阶段残基人工固定为零；阶段通过私有参数传递，不保存可过期的相位状态。第二阶段人工离基统一标为下界侧，防止全局第一阶段列界将非基人工误读成正无穷。原有限值、负人工及清理故障守卫全部保留。

这些检查保证当前基表示下的界安全，不替代因子化方向正确性或一般原方程残差认证。正常路径增加一次线性候选复核；若多个候选因舍入逐一失败，最坏为二次复杂度。有限算术不能安全完成时仍可能诚实返回数值失败，不声称已解决所有大数或病态模型。

## 可复现正确性证据

- `01-red-ratio.log`：旧实现针对12个新增比值单测有10个失败；`02-green-ratio.log` 对应12个全部通过。
- 冲突等式 `x=1000+2^-21`、`x=1000`，以及第二行加入 `0.5y` 的变体，现在在两引擎、Min/Max、正反行序、solve/首次resolve下均证明 `Infeasible`。原故障注入仍拒绝坏状态，不将其清理掉。
- 无人工的第二阶段反例：`x,y≥0`，先 `x≤1000+2^-21`，再 `x+0.5y≤1000`，最大化 `x+0.1y`。修后两引擎、目标方向、行序及入口组合均返回目标1000、`x=1000,y=0`，原第二行残差不再为 `2^-21`。
- `06-red-phase2-artificial.log`：`x=1`、`x-1e-10y=1`、最大化y（或最小化-y）的自然模型，严格推出y=0；最初的全界修改尚未固定第二阶段人工，两引擎仍错误返回 `Unbounded`。显式阶段界修复后，两引擎所有组合均诚实返回 `IterationLimit`，因为阻挡主元低于既有阈值，不能宣称完成证明。重复等式 `x=1`、`x=1` 的自由y对照仍正确返回 `Unbounded`。
- 有限宽度 `[-1e308,1e308]` 不能以无限步长翻转：修后零步骤返回 `IterationLimit`，debug不再触发翻转断言panic。不把旧release恰好得到有限端点的行为描述成错误无界。
- `10-green-final-safe-ratio.log`：最终专属28项全部通过，涵盖安全旧并列、方向4/8危险候选、上下界/负入基方向、Bland列号破键、翻转自身阻挡、小主元先阻挡、已花容差、上限舍入后次选、非有限方向与有限算术溢出、人工非基侧、clone/resolve及真正无界。工作额度特性另覆盖拒绝不扣工作步、旧基不变及期限/迭代提示不重置。

`03-green-phase1.log` 留存了一个过时自然例预期的失败：新实现已经证明不可行，旧断言仍要求数值失败；最终把自然例要求提升为不可行证明，并保留独立故障注入要求。`04-default-full.log` 留存8个错误文本兼容性失败：状态行为正确，但初版合并了非有限方向消息；后续恢复旧专用错误文本，未弱化这些断言。
