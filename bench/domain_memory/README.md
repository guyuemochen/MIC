候选使用32列不可变共享块：兄弟节点共用父域快照，未变化的块继续共享；恢复仍得到完整上下界。
不改变节点选择、破键、全局固定、默认DFS、预算或结果语义。没有引入新内存上限。

使用上一轮21例生成集作为回归集，不声称独立泛化验证。优先检查5个主要packing及
覆盖、负系数、200变量边界。固定节点预算关闭墙钟截断，保留启发式而关闭主动降级，
新旧实现逐字段比较终态、目标、界、gap、节点、LP迭代、割、RC统计及解向量。

主对照耗时几何平均比不超过1.10，单例不超过1.25。低内存例记录原值，不夸大百分比。
