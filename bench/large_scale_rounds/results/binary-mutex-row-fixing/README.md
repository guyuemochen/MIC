# 二元互斥固定的两例定点结果

源码冻结在 `b4b2d1000ec34ae68b4e91b53c28442892e2c7f1`。基础和候选共同启用
`sparse_row_products`、`binary_coefficient_strengthening` 和 `root_cut_recheck`。
候选额外启用 `binary_mutex_row_fixing`。两例各有一对 30 秒单线程求解，
使用冻结的节点上限和求解参数，关闭诊断。执行与核验退出码为 0。

| 算例 | 基础下界 | 候选下界 | 基础 / 候选 LP 迭代 | 基础 / 候选峰值 RSS |
| --- | ---: | ---: | ---: | ---: |
| drayage-100-23 | 11714.141979 | 103333.874073 | 175415 / 206561 | 25.94 / 24.98 MiB |
| drayage-25-23 | 11714.141979 | 99718.790531 | 172046 / 204532 | 26.84 / 25.50 MiB |

四次终态均为 `LimitReached`，均有 1 个节点、0 条割和有限对偶下界，尚无整数可行解。
100-23 的候选下界与外部证得最优值一致。25-23 的相应外部最优值为 101282.647018。
独立原模型检查复核了两例的四条 MIC 下界与外部参考解，零正确性错误。定点因两例
下界均改善通过，候选仍默认关闭。

旧生产预处理对两例均固定 0 列。以其缩减模型为起点模拟逐行界传播，分别可固定
1116 和 1066 个弧。正式候选实际固定 3341 和 3315 个弧，完整覆盖逐行模拟结果，
新增 2225 和 2249 个。每条均固定为零，缩减列分别为 7749 和 7775，两例同剩 4435 行。
独立精确有理活动度计算与生产还原映射的原列下标逐一吻合。两例冻结模型的 HiGHS 和
SCIP 已证最优解也都未使用这些弧。

`point.jsonl` 的 `model` 字段改为当前归档相对路径，另外的字段逐项保真；
`relocation.json` 保存搬移前后哈希。搬移后再次核验，28 条记录及 16 个已有解
通过原模型检查。正式门禁在 `point-gate.json`，每例实际固定列在
`*-fixed.tsv.gz`，重跑方法位于 [试验协议](../../binary-mutex-row-fixing.md)。

验证矩阵记录在 `validation-status.tsv`，最终 15 项均退出 0。生产默认与显式互斥
分别通过 495 和 500 个 MILP 单元测试，以及各 29 个 CLI、14 个常规验收和 1 个冷热
差分测试。两组和显式关闭 R12 的旧生产配置各通过 16 个 release 验收。另通过裸
无默认特性、旧根割计数、认证回退与诊断组合专项，planner 127 项、FFI 27 项和 Python
65 项。初次定点启动选择的 Python 缺少 `tomllib`，该次没有启动求解；归档正式运行用
Python 3.13.14。

## 固定 20 例的覆盖

`coverage.json` 用同源基础和候选库运行生产缩放及预处理，逐例核对原模型哈希和
已固定的原列下标。只有两例 drayage 命中新增固定，分别净增 3341 和 3315 列。
20 例均无旧固定删除或改值。其余 18 例的固定集、缩减行列数和聚合组数完全一致。
这 18 例中，bnatt500、seymour、neos17、icir97_tension 原本已分别固定 1971、
117、24、167 列。用协议中的两份 `presolve_*` 探针运行 `binary_mutex_coverage.py`
可重算覆盖，输入为既有 `external-baseline.jsonl` 和 `miplib2017-baseline.jsonl`。

## 首次根 LP 和整数性障碍

另用同一 MILP 源树的候选加 `proof_profile` 构建只读探针。每例在生产缩减后的
Revised 引擎上冷启动求解一次，预算上限 30 秒，未运行启发式和割。两例分别经
5502 和 5800 次迭代证得 LP 最优，目标与正式定点保留的根界一致，第一阶段均已
结束。每例有一个留基人工列，其值通过引擎的零容差终检。映回原模型的 LP 报告点
均通过独立行和变量界检验。

| 算例 | 距整数超过 1e-6 的二元数 | 最大整数偏差 | 逐列取整后的违约行 | 最大违反量 |
| --- | ---: | ---: | ---: | ---: |
| drayage-100-23 | 126 | 0.310229 | 28 | 10960.062378（r1229l） |
| drayage-25-23 | 110 | 0.213390 | 24 | 12803.371002（r2231l） |

两例逐列取整后均满足全部 210 条恰选一行，违约全来自时间顺序。保留取整的弧并
允许重排连续时刻，两例仍不可行。把选弧代入原模型后，用有理数核对时间差约束。
100-23 的行 r4511l、r1031l、r2980l、r2890l、r4580u 组成总差
8601.398132324197 的矛盾环。25-23 的行 r4507l、r794l、r4435l、r4565u 形成
6778.785614013701 的矛盾环。两例的根点说明，解构造需要在选弧时处理路径累计时间窗。

`root-lp/*.tsv.gz` 保存首次 LP 报告点的原列下标与值。解压后把原模型、报告点和
输出路径交给 `binary_mutex_root_lp_audit.py`，可逐项复现 `*-root-check.json`。
如需重跑 LP，仍用冻结提交 b4b2d10 构建 release 库，显式特性为
`binary_mutex_row_fixing,proof_profile`，并用该库链接 `binary_mutex_root_lp_probe.rs`。
复核和选弧使用首次 LP 报告点，外部参考解只用于正式定点的界核验。
