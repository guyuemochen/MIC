# p0201 独立验解

在仓库根目录构建生产探针，使用 Python 3.10 或更高版本运行核验。脚本还会在临时目录复制当前 Rust 源码，编译一个直接调用分组动态规划的入口。生产探针和源码应来自同一版本。

```sh
cargo build --release --manifest-path milp/Cargo.toml --example round_probe
python3 bench/large_scale_rounds/results/circ-p0201/validation/check.py \
  milp/target/release/examples/round_probe --output /tmp/p0201-validation.json
```

脚本按冻结的 SHA-256 校验两份输入，用原始 MPS 逐项对账导入的 201 个二元变量、目标和 133 条约束。最优值 7615 来自 MPS 自带的已证最优记录。对生产求解器返回的每个回调解和最终解，先检查变量与二元值的偏差不超过 `1e-6`，随后用整数运算复算全部约束和目标。归档中的解向量按对应输入的变量顺序保存。

两次等价变换分别重排行、列，改写变量名，并把部分约束乘以负一、翻转不等号。其中一次还将单选组中每个变量的费用减去 503，再对整个目标取负、改成求最大值，变换后的已知最优为 -7112。两次求解都把最终向量映射回原 MPS，核对原约束与原目标。

另外生成 24 个带正负费用的小模型。每个模型含五个三选一分组和两个独立二元变量，脚本逐一检查全部 972 个分组合法赋值。最小化和最大化各有 9 个可行与 3 个不可行模型。每个模型均运行完整和仅允许处理一个状态的两种预算，比较证优值、不可行结论、首解、最终解以及上下界方向。

原题额外检查 1、58,292 和 58,293 三种状态预算。前两次触限，下界均为 5500；最后一次证优，解和界均为 7615。54 次公共入口求解都与直接调用分组模块的状态、处理状态数和界相符。
