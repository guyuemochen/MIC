候选特性 `risk_pivot_refresh` 保持默认关闭。验证源码为同一干净工作树 `8fed85f`，
包含风险候选 `e3a194d`、状态保持测试加强 `777c2cf`、非有限方向守卫及独立验收维护。
具体源码树、构建命令、二进制摘要、测试命令及各日志摘要见 `manifest.json`。

7 项专项全部通过；开启特性的完整 milp 测试 452 项通过、6 项既有忽略；release
验收包含忽略项后 16 项全部通过。默认完整测试和 planner 未重复执行，原因见清单。
两种生产构建均关闭诊断、根基快照和根启发式工作预算特性。

健康背包强制使用稀疏引擎，两组均证优 17，21 次 LP 迭代、6 条割，除耗时外所有
结果字段一致。bnatt500 使用生产 round_probe、单线程、10 秒、2000000 节点、
关闭策略早退，其余默认。输入来自冻结的 MIPLIB 2017 清单，运行前核对模型摘要。

bnatt500 默认组在 2688 次 LP 迭代后返回 LimitReached；候选组推进至 37304 次，
耗时约 10 秒后仍返回 LimitReached。两组均没有可行解或有限界。官方记录为不可行，
本次候选并未完成这个证明。生产构建没有细分终止原因的诊断，不能仅据总状态宣称
新的所有数值失败均已消除。单次功能对照不构成性能结论，后续遵循事前冻结的独立
20 例筛查和配对重复门槛，不据 bnatt500 调主元接受容差。

`functional-results.json` 及每例 JSON 保留完整命令、输入/源码/二进制摘要及结果；
