# 第一阶段负人工变量验证

本轮修复有限负人工变量被正部和或后续零步换基吞掉、进而误报最优的漏洞。第一阶段首次定价前和每步后都要求基本值有限、残基人工值不低于 -feas；稀疏数值重试和风险刷新后重新检查。异常只报告 IterationLimit、目标 NaN，并保留第一阶段欠账，不冒充不可行证明。

比值测试、并列破键、容差、第二阶段策略与计费规则未改变。阶段终了人工正部和继续保留原算术顺序，并增加负值防御；清理逐行置零前以及最终交接时要求残基人工有限且在 ±feas 内，防止清理中的重构改写残人工后被忽略。清理正值漂移及最终复查属于审查发现的恢复路径防御，未声称有自然输入反例。

## 公开反例和红灯

独立审查者提供的公开接口复现及原始输出保存为 public-reproducer.rs、original-public-red.log。其模型 x≥0、零目标，依次加入 x=1000+2^-21 和 x=1000：旧 Dense/Revised、Minimize/Maximize 均一步误报 Optimal，原等式残差为 2^-21（约 476 倍默认可行性容差）。互换行顺序则均为 Infeasible。原始日志从 /tmp/mic_phase1_negative_artificial.log 原样复制，未在本轮冒充重新运行。

本隔离树在新默认基线上新增自然回归后首次编译成功，实际运行红灯为 4 失败、2 通过（01-first-compile-old-red.log，退出码101）。除了上述单变量模型，还验证 x,y≥0、依次 x=1000+2^-21 与 x+0.5y=1000 的自然载体，旧代码同样误报 Optimal；该载体允许下一零步主元把负人工换成非基，因此仅检查最终人工正部和不足。修复后两个载体均在第一步之后拒绝，零步换出尚未发生；双目标方向、两引擎及首次 solve/resolve 均覆盖。反序仍保留 Infeasible。
