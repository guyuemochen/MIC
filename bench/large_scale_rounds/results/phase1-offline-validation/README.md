# 第一阶段捕获离线核验

离线工具以 schema 1 的 `phase1_progress_probe` JSON 为输入。运行 `python3 bench/inspect_phase1_capture.py 捕获.json`，在标准输出获得分层 JSON。可传 `--input` 记录输入文件的 SHA-256，并用 `--solver-commit`、`--build-options`、`--probe-args` 原样记录采集来源。外层模型的数据只用于来源识别，行和变量核验采用 `engine_input_lp` 坐标。当前采集程序使用指定引擎和单线程，开启自适应启发式，其余选项沿默认，与其他性能探针的配置可能不同。

检查每个快照的结构向量位值、人工变量、当前界、构造时界、归一原约束、增广方程，以及引擎输入的原尺度与除以最大系数后的违反量。近零输入行沿原尺度与记录的可行容差比较，已入表的割按其记录的原尺度检查。增广方程每行的相对后向误差取 `|Mv-b| / (Σ|m_j v_j|+|b|)`，分子和分母同时为零时记零。行求和先用 `math.fsum`，临界、显著抵消及双精度溢出时由原始二进制数转 `Fraction` 复核。算术溢出、必需数据缺失、采集省略、非有限快照和来源映射异常保留为证据不足。人工变量复核使用第一阶段的非负界，并保留正部和、负部和与绝对和。定价只有在迭代与状态世代均相符时才与候选关联。

`01-unittest.log` 记录 7 项内置测试全部通过。扰动包含原约束、当前界、人工映射、割与近零行、缺失或省略、NaN、正负无穷、负零和求和顺序。`02-dense.json` 和 `02-revised.json` 来自已归档的双等式捕获。两份捕获的 `first_candidate` 均在调用内第 1 次迭代、状态世代 1，通过原始点和增广方程核验。同世代定价为 `optimal`，证据显示正常第一阶段收尾。`03-fixture-check.log` 逐一列出快照结论。

所有结论均是对保存向量按所记录容差所做的数值诊断。没有重新求基方程或优化 LP，也没有运行公开模型。结果不能证明清理成功、第二阶段最优或外层 MIP 可行性。

边界复审补入 `boundary-capture.json`。保存的两个 binary64 数的界差直接相减会舍入为 `1e-9`，精确差比容差多 `1/19342813113834066795298816`。原约束和增广方程残差均为零，界违反足以使候选未通过。上下界均在差值舍入到容差时用精确分数判断，最坏列保留 `exact_violation`。已有人工正部和临界复核沿用精确分数判断，并在 `positive_sum_exact` 保留复核值。新增测试覆盖上界反射、合法负零和正无穷界、差值恰等容差及单个人工值合格但正部和超差。`04-boundary-unittest.log` 中 9 项全通过，`05-boundary-report.json` 保存修正后的原始复现结论。
