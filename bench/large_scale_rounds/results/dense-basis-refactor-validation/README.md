第一轮本次第二阶段数值失败且无人工欠账时，在原余额与期限允许下，优先从当前原行/松弛列组装当前 B 并调用既有稀疏 LU。只在临时内存重建 rhs、逆矩阵及全部静态表格列；每次三角解按原 B 核对绝对 feasibility 残差，还核对基本界、当前原行/割可行性以及带松弛的原等式。没有夹界或放宽容差。准备通过且期限允许后才整体提交，退休全部非基贴零旧人工，完整重建索引。当前基含人工、不适用或数值准备失败才选择旧冷重建。fresh 成功后再次失败不能再冷重建，仍最多两个求解 attempt。
