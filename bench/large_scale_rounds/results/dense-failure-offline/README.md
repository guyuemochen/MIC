# lseu 失败基的独立离线核验

输入是同源诊断的四份完整快照，两个调用各包含原尝试与唯一冷重试。每份为112行、89个结构变量，基列全部属于静态列；仍有83或82个人工列，但全部非基，未凭逆矩阵猜测人工原行。按保存的原始行、松弛列符号和基列次序重新组装当前基矩阵B。非基结构变量按当前端点取值，非基松弛为零，并检查了全部基标志、维度和有限性。

`inspect.py`没有调用MIC或重新优化LP，只执行保存值的算术核验和独立NumPy基方程求解。四份生产刷新结果均逐位复演一致；原尝试和重试的状态一致，因此两组分析也一致。

| 保存逆矩阵乘B偏离单位阵的最大值 | 0.0254577 | 0.0372410 |
| 独立重解后的最大基界违反 | 1.009e-12 | 1.009e-12 |
| 独立重解后的原规范化行违反 | 1.009e-12 | 1.008e-12 |
| 重解向量对精确表示输入的基方程残差 | 8.733e-14 | 7.386e-14 |

记录的可行性容差为1e-9。将保存逆矩阵与原双精度右端相乘改成Fraction精确算术，或同时把右端改成保存浮点输入的精确二进制有理值，仍有相同量级的越界。右端自身舍入约7.8e-14；末次乘加或右端舍入不足以解释这里的主要误差。保存的逆矩阵已经偏离当前B的逆，重新冷启动则重复了同一累积路径。

独立重解采用`numpy.linalg.solve`，未调用MIC的分解实现。基条件数的无穷范数估计约7.00e5和6.05e5。新向量的基方程残差使用保存浮点输入的Fraction算术复核；表中原行违反针对报告的双精度结构向量计算。位于不同快照的同一个行号不代表相同基列，完整列映射在输入中保留。

这些数据支持实验性地重新分解当前基，并同步重建表格、逆矩阵和基本值；只替换基本值不足以修复其余状态。双精度新解及其小残差不是精确最优性或不可行证书，也不保证在线恢复一定成功。没有修改容差、预算或B&B终态规则。审查确认了构B、非基本值、行符号和原始x位值；后续生产策略仍须通过测试和真实模型验证。

来源、脚本摘要、复现命令、NumPy版本及请求的单线程环境变量见`manifest.json`。`analysis.json`保留第一次运行的真实临时输入路径，来源文件摘要与仓库归档一致。
