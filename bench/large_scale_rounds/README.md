# 大规模逐轮开发验证（2026-11-12）

基线 b7f11a1。每轮先冻结判据，再运行测量；不并发编译或求解，不覆盖旧记录和真值。
零新增 Rust 依赖、无 unsafe；单线程破键、状态诚实性和 FFI ABI 1 保持。

## 第一轮：稀疏缩放

只改变缩放工作矩阵的表示，合法模型的因子、系数、界和右端须逐位一致。
旧实现留在测试参考中；主求解路径不提供动态选择，不拟合密度阈值。

`scale_probe` 分别记录生成/校验、缩放、完整入口求解耗时；缩放摘要包含所有浮点位模式。
RSS 用独立进程的系统峰值，包含原模型、输出模型、运行库及测量开销。
新旧版本使用完全相同的探针源码与工具链，各三次串行，重复轮次反转执行顺序。

- 缩放：1000、3000、8000 行/列，每行 8 项，连续/整数/混合变量；另测原有宽LP、
  稀疏LP、混合整数和集合覆盖模型。所有摘要必须一致。
- 容量：候选独跑 25000、50000、100000 行/列，每行 8 项，不运行旧版的超大稠密分配。
  维数翻倍且非零数翻倍时RSS增长应不超过2.5倍；100000维RSS应低于512MiB。
- 完整求解入口：独立单系数不等式、负目标、已知最优全零的容量模型；小尺寸新旧对照，
  候选扩到100000维。该模型只验证准备阶段容量，不能作为通用困难MIP的性能证据。
- 保留门槛：正确性全部通过，8000维混合模型RSS至少减半、缩放至少快2倍；已有模型的
  缩放中位耗时在基线≥0.01秒时不得回退25%以上。低于此值报告绝对差、不放大百分比。

还要跑milp全测、release验收、planner全测。完整求解对账比较终态、目标、界、节点、
LP迭代和解向量；耗时、统计时间不参与确定性比较。

## 第二、三轮：停止政策与强分支证明复用（事前矩阵）

停止政策使用`--early-stop on|off`，原默认on不翻；off保留auto启发式，只禁止停滞提前退出。
该轮是明确用户控制语义，不以“更早退出”作提速证据。强分支复用默认关闭，只复用本次
最终所选变量的两侧证明；没有实际更紧子界时，不额外开启非整数前沿剪枝。

统一原模型对照采用同一工具链、单线程、10秒硬搜索预算、2000000节点；加载/建模与solve
分开，MIC不再跑额外根界旁路。节点定义因求解器不同，不拿相同节点上限冒充相同工作量。
外部HiGHS1.15.1、SCIP10.0.0（OR-Tools9.15.6755），相对/绝对gap设0；数值容差不声称完全相同。
用户暂没有Gurobi授权，本轮按其答复先对标HiGHS/SCIP。

- 历史回归：knapsack-5000、mknap-5x300、setcover-300x600、lp-sparse-4000x800；
  公开p0033、p0201、enigma、stein27。均只作回归，不称独立留出。
- 本轮未测公共模型：p0282、p0548、lseu、air03；名单在下载与求解前固定，转换不支持的
  模型须明示排除，不能按性能换模型。此次八个公共模型均转换成功。
- 基线外部对照：MIC early-stop off、probe-reuse off 与两外部各3次，顺序轮换；
  保存完整原模型、每个可行解、有效界、实际状态、时间和RSS，并独立检查。
- 强分支首轮筛查：上述12例，auto分支规则、early-stop off，reuse off/on各一次；
  另以pseudo显式规则在p0033、p0201、lseu三例做独立机制检查。所有状态/目标/界均保留，
  默认MostFractional不因本实验自动换成pseudo。
- 若没有正确性问题，再对mknap-5x300、knapsack-5000、p0033-pseudo、lseu-pseudo各3次
  off/on交替，比较完整证明；未证优的记录只比较可行解/界和预算内证明能力。
- 强分支默认推广门槛：零正确性错误、不丢原来可完成的证明、共同证优且基线≥0.05秒
  的实例至少3个、几何平均耗时比≤0.90、单例中位≤1.25倍、RSS≤max(64MiB,2倍对照)。
  不达标则保持显式实验或撤出生产入口，保留证据，不围绕本集合继续调阈值。

## 第四轮：受影响行乘积（事前矩阵）

独立分支codex/sparse-row-products，默认关闭特性，保持每列浮点累加顺序和定价规则。
仅当实际访问项估计`触及项+2m+3n < 目标CSC项`时走行累加；Bland定价保留原路。
不据本轮结果调阈值。诊断计数与正式计时分开构建。

首轮使用原始LP松弛：lp-sparse-4000x800、lp-wide-1000x2000、setcover-300x600，
以及旧扫描留出生成器产生的新种子稀疏宽/稀疏高/中密度/密集宽四例（首次测量前记录种子与SHA）。
新旧三次交替，状态、目标、迭代数一致；另用测试确认解/基/权重逐位一致。
保留门槛：目标稀疏LP至少快10%，七例几何平均≤0.95、单例≤1.10，RSS≤1.10倍或绝对多用≤8MiB。
若门控很少命中或总成本上升，记录负结果，不默认合入。
