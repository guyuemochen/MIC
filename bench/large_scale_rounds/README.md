# 大规模逐轮开发验证（2026-11-12）

基线 b7f11a1。每轮先冻结判据，再运行测量；不并发编译或求解，不覆盖旧记录和真值。
零新增 Rust 依赖、无 unsafe；单线程破键、状态诚实性和 FFI ABI 1 保持。

## 第一轮：稀疏缩放

只改变缩放工作矩阵的表示，合法模型的因子、系数、界和右端须逐位一致。
旧实现留在测试参考中；主求解路径不提供动态选择，不拟合密度阈值。

`scale_probe` 分别记录生成/校验、缩放、完整入口求解耗时；缩放摘要包含所有浮点位模式。
RSS 用独立进程的系统峰值，包含原模型、输出模型、运行库及测量开销。
新旧版本使用完全相同的探针源码与工具链，各三次串行，重复轮次反转执行顺序。

- 缩放：1000、3000、8000 行/列，每行 8 项，连续/整数/混合变量；另测原有宽LP、
  稀疏LP、混合整数和集合覆盖模型。所有摘要必须一致。
- 容量：候选独跑 25000、50000、100000 行/列，每行 8 项，不运行旧版的超大稠密分配。
  维数翻倍且非零数翻倍时RSS增长应不超过2.5倍；100000维RSS应低于512MiB。
- 完整求解入口：独立单系数不等式、负目标、已知最优全零的容量模型；小尺寸新旧对照，
  候选扩到100000维。该模型只验证准备阶段容量，不能作为通用困难MIP的性能证据。
- 保留门槛：正确性全部通过，8000维混合模型RSS至少减半、缩放至少快2倍；已有模型的
  缩放中位耗时在基线≥0.01秒时不得回退25%以上。低于此值报告绝对差、不放大百分比。

还要跑milp全测、release验收、planner全测。完整求解对账比较终态、目标、界、节点、
LP迭代和解向量；耗时、统计时间不参与确定性比较。

## 后续轮次

强分支结果复用先默认关闭实验；区分父目标与子树有效界，验证局部割作用域和限额。
停止政策解耦保持旧默认，以显式开关保留启发式但禁用提前降级。
后续具体测量矩阵和保留条件在首次运行前另行记录，历史公开集仅作回归。

## 第二、三轮：停止政策与强分支证明复用（事前矩阵）

停止政策使用`--early-stop on|off`，原默认on不翻；off保留auto启发式，只禁止停滞提前退出。
该轮是明确用户控制语义，不以“更早退出”作提速证据。强分支复用默认关闭，只复用本次
最终所选变量的两侧证明；没有实际更紧子界时，不额外开启非整数前沿剪枝。

统一原模型对照采用同一工具链、单线程、10秒硬搜索预算、2000000节点；加载/建模与solve
分开，MIC不再跑额外根界旁路。节点定义因求解器不同，不拿相同节点上限冒充相同工作量。
外部HiGHS1.15.1、SCIP10.0.0（OR-Tools9.15.6755），相对/绝对gap设0；数值容差不声称完全相同。
用户暂没有Gurobi授权，本轮按其答复先对标HiGHS/SCIP。

- 历史回归：knapsack-5000、mknap-5x300、setcover-300x600、lp-sparse-4000x800；
  公开p0033、p0201、enigma、stein27。均只作回归，不称独立留出。
- 本轮未测公共模型：p0282、p0548、lseu、air03；名单在下载与求解前固定，转换不支持的
  模型须明示排除，不能按性能换模型。此次八个公共模型均转换成功。
- 基线外部对照：MIC early-stop off、probe-reuse off 与两外部各3次，顺序轮换；
  保存完整原模型、每个可行解、有效界、实际状态、时间和RSS，并独立检查。
- 强分支首轮筛查：上述12例，auto分支规则、early-stop off，reuse off/on各一次；
  另以pseudo显式规则在p0033、p0201、lseu三例做独立机制检查。所有状态/目标/界均保留，
  默认MostFractional不因本实验自动换成pseudo。
- 若没有正确性问题，再对mknap-5x300、knapsack-5000、p0033-pseudo、lseu-pseudo各3次
  off/on交替，比较完整证明；未证优的记录只比较可行解/界和预算内证明能力。
- 强分支默认推广门槛：零正确性错误、不丢原来可完成的证明、共同证优且基线≥0.05秒
  的实例至少3个、几何平均耗时比≤0.90、单例中位≤1.25倍、RSS≤max(64MiB,2倍对照)。
  不达标则保持显式实验或撤出生产入口，保留证据，不围绕本集合继续调阈值。

## 第四轮：受影响行乘积（事前矩阵）

独立分支codex/sparse-row-products，默认关闭特性，保持每列浮点累加顺序和定价规则。
仅当实际访问项估计`触及项+2m+3n < 目标CSC项`时走行累加；Bland定价保留原路。
不据本轮结果调阈值。诊断计数与正式计时分开构建。

首轮使用原始LP松弛：lp-sparse-4000x800、lp-wide-1000x2000、setcover-300x600，
以及旧扫描留出生成器产生的新种子稀疏宽/稀疏高/中密度/密集宽四例（首次测量前记录种子与SHA）。
新旧三次交替，状态、目标、迭代数一致；另用测试确认解/基/权重逐位一致。
保留门槛：目标稀疏LP至少快10%，七例几何平均≤0.95、单例≤1.10，RSS≤1.10倍或绝对多用≤8MiB。
若门控很少命中或总成本上升，记录负结果，不默认合入。

## 第五轮：二元变量静态行传播（事前矩阵）

独立分支默认关闭 `--binary-propagation on|off`。用同一个新 MIC 二进制逐次切换，
重新导出每个模型并和外部基线的原模型哈希核对。复用外部基线名单和模型做正确性对账，
实际关闭组耗时由新二进制重测。保存二进制哈希、源码提交和源码树哈希。

- 筛查沿用第二、三轮外部对照的固定 12 例，关闭和开启各一次。使用单线程、10 秒、
  2000000 节点、auto 分支，关闭策略提前停止和强分支结果复用。
- 筛查无正确性错误时，同 12 例各跑三次关闭和三次开启，按重复轮次反转执行顺序。
  不按筛查表现增删算例。保存状态、原尺度目标和界、完整可行解、节点、LP 迭代、
  传播计数和每个进程的峰值 RSS。用原模型验证解，并与 HiGHS、SCIP 的已证结果对账。
- 默认推广先要求零正确性错误、每条关闭组已完成的证明都保留、每次开启组的 RSS
  ≤ max(64 MiB, 2 倍同次关闭组)，且三次均共同证优的每例耗时中位数比 ≤ 1.25。
  耗时几何平均只纳入两组各三次均证优且关闭组中位耗时 ≥ 0.05 秒的模型，至少需 3 例。
- 同时满足以下一条性能门槛。其一，有效例耗时比的几何平均 ≤ 0.90。其二，至少
  2 个模型在关闭组的三次运行中均未完成证明、在开启组的三次运行中均证优，
  且有效例几何平均 ≤ 1.05。未共同证优的算例只比较证明完成情况、解和界。
  不达标则保留默认关闭或独立实验分支，不根据结果调整阈值。

## 第六轮：MIPLIB 2017 公开留出输入（事前冻结）

从 [MIPLIB 2017 Benchmark Set](https://miplib.zib.de/tag_benchmark.html) 和
[官方 v2 名单](https://miplib.zib.de/downloads/benchmark-v2.test) 按名字核对 240 例及变量计数。
只取含整数变量的实例。小规模层要求变量数和约束数均 ≤ 10000、非零项 ≤ 200000，
分为全二元、二元加连续和含一般整数三层。大规模层要求至少一项维数 > 10000，
且两项均 ≤ 50000、非零项 ≤ 500000。每层将
`sha256("MIC-MIPLIB2017-R6-20261112:" + 算例名)` 升序排列并取前两例。
分层和排序只使用名字与模型计数。官方解文件仅用于后续核验。

- 全二元：`bnatt500`、`seymour`。
- 二元加连续：`neos17`、`neos-4954672-berkel`。
- 含一般整数：`gen-ip054`、`icir97_tension`。
- 大规模：`drayage-100-23`、`drayage-25-23`。

两例大规模模型来自同一个 drayage 家族。这八例是按规则抽取的留出样本，无法代表整个
240 例基准集。先保存冻结选择和官方名单、元数据、版本解文件的 URL 与 SHA-256，
再从算例详情页下载原 MPS。转换无法无损保留的算例记录原因，保留原始文件和冻结名额。
`compare.py --public` 使用模型目录内的 `sources.json`，仓库留存同内容的清单供复核。

首轮外部筛查三者单线程、每例30秒、2000000节点、gap目标0，各一次，按算例轮换顺序。
MIC用当前默认传播Auto，显式关闭停滞早退和探测证明复用。完整保存解/界并独立复核，
包括官方标为不可行的bnatt500；单次筛查只定位失败与差距，不据耗时推广任何新默认。
模型读取/转换在计时前完成，求解时不并行编译或运行其它求解器。

证明瓶颈诊断使用同一生产round_probe入口，禁止用另建LP的profile_stats旁路冒充根界。
先对旧的五个未证优例（setcover-300x600、p0201、p0282、p0548、lseu）各跑
node_limit=1、root_cuts off/on；固定MF、pc_probes=0、reuse off、传播on、RC on、
localcuts off、earlystop off、单线程10秒。只有已完成根处理且仍限额、界有限时才能
把记录解释为根界；Optimal记录可能由incumbent替代前沿界，不能反推原LP界。
随后对旧五例与新八例固定五配置，各单线程10秒一次、根割on/局部割off/RC on/
传播on/reuse off/earlystop off：A=DFS+MF，B=Hybrid+MF，C=DFS+PC0，D=DFS+PC8，
E=Hybrid+PC8。不按成绩删除配置或换模型。该矩阵用于分辨调度、被动伪代价和
可靠性探测，不直接作默认推广判据；若发现正确性错误，先保留证据并修复，再继续。

## 第七轮：根阶段重复LP与启发式工作量（首次候选测量前冻结）

第六轮真实阶段观测表明，neos17等模型的初始LP很快完成，但根潜水耗尽预算；
seymour还重复冷解同一个根LP。独立修复根证据丢失与LU失败状态安全后，四组统一
使用同一源码树：base、仅root_snapshot_restore、仅root_heuristic_work_budget、两者。
两项特性均默认关闭；正式计时不启用proof_profile。快照仅替代预割潜水后的冷重解，
须先对账同一根基和真实工作记账。预算组跨预割/割后潜水及sub-MIP共享
`max(1000,4×初始根LP迭代数)`次LP迭代和1000次LP调用；割循环、主搜索与MITM
不扣该预算。只在调用边界检查，所以允许超出最后一次LP调用，不能宣称硬墙钟预算。
规则在任何候选性能测量前确定，不按模型调整。

筛查固定旧12例加新8例，共20例，每组一次、单线程10秒、2000000节点，开启原默认
启发式和传播Auto，关闭停滞早退与证明复用，其余生产默认；四组按模型轮换顺序。
每个新二进制重新导出并核对原模型哈希，保存完整解、界、状态、RSS及源码/二进制摘要。
正确性错误先修；不以超时耗时的比值称提速。候选选择先排除丢失base已完成证明的组，
再依次比较新8例证明数、全部20例证明数、共同证优模型耗时，仍并列时优先较少特性。
若有可保留候选，用同工具base/候选两组对全部20例各30秒、各3次重复，轮换顺序；
推广门槛沿用第五轮的零错误、每条证明不丢、RSS、单例1.25倍和共同证优至少3例的
几何平均≤0.90，或至少2例新增稳定证明且几何平均≤1.05。未达标保持默认关闭，
不借本轮重新调预算系数。此门槛表示局部改动可保留，不表示达到整个MIPLIB的外部水平。

## 第八、九轮：独立验证系数加强与风险换基复核（首次候选测量前冻结）

两项分别使用`run_feature_trial.py`测量，禁止合并特性后归因。基础组与候选组必须来自
同一干净源码树，包含已经验证的正确性修复；根阶段两项实验继续关闭。第八轮唯一
额外特性为`binary_coefficient_strengthening`，第九轮为`risk_pivot_refresh`。
前者先通过整数可行域保持测试及缩放后模型的独立精确算术核对；后者先通过旧基
重构、重新定价、预算/期限不重置和失败恢复测试。任何错误先修，不能靠关闭检查放行。

模型、参数、轮换顺序和计时证据沿用第七轮的20例矩阵：先10秒一次筛查，正确性
通过且不丢基础组证明的候选再做30秒三次配对。正式二进制关闭所有诊断特性。
推广仍须零正确性错误、每条基础组证明保留、每次RSS不超过max(64MiB,2倍配对基础组)、
共同证优每例中位耗时比不超过1.25，且至少3例基础中位耗时达到0.05秒；在此基础上，
有效例几何平均比不超过0.90，或至少2例新增三次均完成的证明且几何平均不超过1.05。
未通过保持默认关闭。bnatt单例数值恢复成功只能证明修复了该失败路径，不能单凭
这一例宣布通用性能达标，也不据其结果调整主元接受容差。

`run_root_work.py` 和 `run_feature_trial.py` 在导出模型前用独立进程验证系统计时器可返回
有效峰值 RSS。预检失败会报告计时环境问题并退出，此时结果文件尚未创建。

## 第十轮：根启发式单次 LP 工作步限额（首次候选测量前冻结）

主对照使用 `run_feature_trial.py --feature root_heuristic_work_limit`。基础组不启用任何
实验特性，候选组仅显式开启默认关闭的 `root_heuristic_work_limit`。Cargo 同时启用其依赖
`root_heuristic_work_budget`，构建记录保留这项隐含依赖。两组使用同一干净冻结源码树，
均关闭快照恢复、二元系数加强、风险换基复核和诊断特性。

启发式预算按实际换基主元和算法性界翻转计工作步，沿用
`max(1000, 4 × 初始根 LP 迭代数)` 与 1000 次 LP 调用的上限。原 LP 迭代统计口径保持不变。
这些工作量上限不构成硬墙钟保证。

沿用固定的 20 例、单线程、2000000 节点和第七轮生产参数。先各跑一次 10 秒筛查；
仅在零正确性错误、保留每条基础组证明、每次 RSS ≤ max(64 MiB, 2 倍基础组)，且共同
证优的每例耗时比 ≤ 1.25 时，再对同 20 例各跑三次 30 秒配对。模型和顺序按同一矩阵轮换。
默认推广沿用上述正确性、证明、RSS 和单例耗时门槛，并要求至少 3 例在两组各三次均证优
且基础组中位耗时 ≥ 0.05 秒。在这些有效例上，候选耗时比的几何平均须 ≤ 0.90；
或至少 2 例基础组三次均未完成证明、候选组三次均完成证明，且几何平均 ≤ 1.05。
未共同证优的算例只比较证明、可行目标和界。未达标保持默认关闭。

另用同一源码构建两份诊断探针。旧组开启 `root_heuristic_work_budget` 和 `proof_profile`，
新组开启 `root_heuristic_work_limit` 和 `proof_profile`。两组只在 `drayage-100-23`、
`drayage-25-23` 各运行一次，单线程、节点上限 1、时间上限 10 秒，其余参数与主对照相同。
保存根启发式预算消耗和根证据恢复快照，作为阶段行为核验；诊断数据不纳入正式耗时或推广判据。
